# Uber Trip Analysis Dashboard | Power BI

## Project Overview

This project is an end-to-end Power BI business intelligence dashboard built to analyze Uber trip booking performance, revenue trends, trip efficiency, and customer ride behavior.

The dashboard helps stakeholders make data-driven operational and pricing decisions by identifying booking patterns, peak demand periods, high-performing locations, and customer vehicle preferences.

---

## Business Problem

Ride-sharing businesses generate massive trip data daily, but raw transactional data alone does not support quick decision-making.

Stakeholders need visibility into:

- Booking trends
- Revenue generation
- Trip efficiency
- Customer ride behavior
- Peak demand timing
- Vehicle utilization
- Pickup/dropoff location trends

Without a centralized dashboard, operational optimization becomes difficult.

---

## Objective

Build an interactive Power BI dashboard that transforms raw Uber trip data into actionable business insights for operations, pricing, and customer experience improvement.

## Dashboard Features

### 1. Overview Dashboard

Includes:

- KPI cards
- Dynamic measure selector
- Payment type analysis
- Trip type analysis (Day/Night)
- Vehicle type matrix
- Daily booking trend

---

### 2. Location Analysis

Insights on:

- Most frequent pickup point
- Most frequent dropoff point
- Top 5 booking locations
- Farthest trip analysis
- Preferred vehicle by pickup location

---

### 3. Time Analysis Dashboard

Includes:

- 10-minute pickup interval analysis
- Day-wise booking trend
- Hour vs Day heatmap
- Peak demand detection

---

### 4. Detailed Drill-Through Dashboard

Includes:

- Detailed trip records
- Drill-through navigation
- Full data view bookmark
